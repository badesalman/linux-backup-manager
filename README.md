# Linux Backup Manager

A Linux-based interactive backup management system written in C++.

## Features
- Create and manage directory backups
- Real-time synchronization using inotify
- Multiple target backup locations
- Restore backups
- Active backup listing
- Symbolic link support
- Parallel execution using child processes

## Technologies
- C++
- UNIX/Linux
- inotify API
- Process management
- File system operations

## Concepts Practiced
- System programming
- Directory monitoring
- Synchronization
- Error handling
- Process creation and management

## Purpose
This academic project was created to practice Linux system programming, filesystem operations, and process synchronization.
